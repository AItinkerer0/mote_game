# mote

검은 공간에서 빛 물방울이 모든 걸 흡수해 **무한히 성장**하는 미니멀 아케이드 게임.
의존성 없는 단일 `index.html` (vanilla JS + Canvas).

> "컨셉 없는 게 컨셉" — 순백의 몽글한 빛 물방울, 순수한 검은 배경. 헝그리샤크식 무한 성장 + 무한 줌아웃 트릭.

## 플레이
- **이동**: 마우스(또는 방향키)로 물방울을 끌고 다닌다.
- **성장**: 작은 먹이와 나보다 작은 세포를 흡수해 커진다. 커질수록 화면이 줌아웃되며 더 큰 것들이 먹이가 된다.
- **위험**: 나보다 큰 면역세포는 쫓아오고 부딪히면 손해 — 피하거나 더 커져서 삼켜라.
- **티어**: 일정 크기마다 세계의 팔레트(색)가 바뀐다.
- **환생 (prestige, `Enter`)**: 지금 크기를 코인으로 정산하고 다시 작게 시작.
- **상점·도감**: 코인으로 `gacha`를 돌려 주인공 색/모양, 먹이, 배경 **스킨**을 모으고 장착(도감에서 확인).

## 특징
- 무한 줌아웃 성장 — 수치는 누적되지만 화면상 크기는 줌으로 관리.
- 물방울 물성·흡수 연출, 발광 글로우 비주얼.
- 스킨 시스템: 주인공 색·모양(블랙홀·별똥별·고리·음파·위성무리), 먹이 색·모양, 배경(성운·심해·오로라·입자장 등). 배경 미리보기는 실제 플레이 화면을 그대로 축소해 보여줘 일치.
- 동전 정산 효과음, BGM, 흡수 효과음.

## 실행
- 로컬: `index.html`을 브라우저로 바로 열기, 또는 정적 서버로:
  ```
  python3 -m http.server 8000
  # http://localhost:8000
  ```
- (선택) GitHub Pages로 배포하면 바로 플레이 링크가 생긴다.

## 기술
- 단일 HTML 파일, 외부 라이브러리·빌드 단계 없음.
- Canvas 2D, Web Audio API.
